# Eval Profile

## 採用した評価観点

| ID | 採用理由 |
|---|---|
| DIM-001 | 日記からX投稿案を作る主要業務が成功する必要がある |
| DIM-003 | X投稿は外部公開を伴う高影響操作のため |
| DIM-004 | 同じ入力で安定して280字以内の投稿案になる必要がある |
| DIM-005 | ユーザーが投稿前に判断できる説明が必要なため |

## 採用したテスト観点

| ID | 採用理由 |
|---|---|
| TVP-001 | 代表的な日記から投稿案を作る正常系を確認する |
| TVP-002 | 長文や文字数境界を確認する |
| TVP-003 | 不足入力や公開リスクのある入力を確認する |
| TVP-006 | 実投稿前の確認・停止を確認する |
| TVP-007 | Skillの出力が運用判断に十分か確認する |

## 採用したケースパターン

| ID | 採用理由 |
|---|---|
| PAT-001 | 主要操作を1回実行して期待結果を確認する |
| PAT-002 | 長文・複数条件でも期待状態を保てるか確認する |
| PAT-003 | 不備入力や危険入力で安全に止まれるか確認する |
