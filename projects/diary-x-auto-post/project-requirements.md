# diary-x-auto-post

## 入力

- interview-summary: `interview-summary.md`

## 目的整理

- 背景: 日記を書いたあと、その内容をXへ投稿する作業を自動化したい。
- 課題: 日記をX向けに整える手間、投稿画面への転記、公開リスク確認が発生している。
- 期待効果: 日記からX投稿文作成、必要に応じた投稿準備、誤投稿防止を一連のSkillで扱える。
- 制約: X投稿は外部公開を伴うため、最終送信は明示許可が必要。API連携はPoC範囲外。
- 未確定事項: 文体、ハッシュタグ、入力元、投稿頻度。

## 曖昧さの整理

- 理解したこと: 最小手段はCodex Skill。日記をX投稿文へ変換し、ブラウザで投稿準備する手順を再利用化する。
- 確認が必要な点: 完全自動投稿を許可する条件、Xアカウント、好みの文体。
- `TBD` で進める点: 投稿文体、ハッシュタグ、日記入力元。

## 解決手段の選定

- 選定した手段: Codex Skills
- 選定理由: 繰り返し作業の手順、判断境界、チャット出力形式を再利用可能にするのが最小。
- 採らなかった案: Web AppはUI構築が過剰。GPTsはブラウザ操作やローカルSkillとしての再利用に弱い。Workflow設計のみでは実用成果物にならない。
- トレードオフ: 初期版はX API連携を持たず、ブラウザセッションに依存する。

## 成立条件

- 想定ユーザー: 日記を書いた本人。
- PoC成立条件:
  - 日記本文から280字以内のX投稿案を生成できる。
  - 公開に向かない情報を検知し、投稿前に止まれる。
  - 明示許可がない限り、Xへの最終投稿を行わない。
  - Skillとして `SKILL.md` と必要な参照ファイルが作成され、基本検証に通る。
