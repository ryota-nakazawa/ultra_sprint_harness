# eval-cases.md

## 基本情報

- プロジェクト名: cosmetics-ec
- ルート種別: Web App

## 評価観点

- 業務成功: 商品選択から注文完了まで進めるか。
- 誤実行: 不足入力で注文完了しないか。
- 安全性: 注文確定前に内容確認ができるか。
- 再現性: カート操作後の金額が一貫するか。
- 運用負荷: デモ注文であることを説明しやすいか。

- 実商品画像と正式価格を入れた時にカードの高さや文言が崩れないか。
