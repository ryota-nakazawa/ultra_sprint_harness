# Interview Summary

## 背景

- 化粧品をオンラインで販売できる EC サイトのプロトタイプが必要。
- 詳細なブランド、商品構成、決済方式、配送条件は未確定。

## 課題

- 商品を魅力的に見せながら、購入までの導線を短く確認できる画面が必要。
- 実決済や会員認証を作る前に、EC として最低限成立する UX を検証したい。

## 期待効果

- 商品閲覧、カート投入、購入者情報入力、注文完了までの流れをブラウザで確認できる。
- 化粧品ブランドとしての見た目、情報密度、購入導線についてフィードバックを得られる。

## 制約

- PoC では実決済、実在庫、会員認証、外部配送 API は扱わない。
- 商品、価格、送料条件は仮データ。
- 化粧品表示上の法規制チェックは対象外。医薬的効能を断定しない文言にする。

## 未確定事項

- ブランド名、正式商品名、商品点数、価格、配送条件、決済手段、返品ポリシー。
