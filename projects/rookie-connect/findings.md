# Findings — Rookie Connect

## 初回実装の判断

- 会話を始める主導線を中央の投稿欄に固定し、投稿・いいね・返信を各投稿の直下へ集約した。
- 実ユーザー、認証、保存を含めず、投稿状態はブラウザ内だけで保持することで PoC の検証対象を「会話を始めやすいか」に絞った。
- 画像ではなく文字アバターを用い、権利・個人情報の扱いを持ち込まずに人の気配を作った。

## 確認できたこと

- `node --check app.js` は成功した。
- `http://127.0.0.1:3000/`、`styles.css`、`app.js` は HTTP 200 で配信された。

## 次の利用者確認

- 初見の新人が説明なしで投稿・いいね・返信の場所を見つけられるか。
- 本番化を検討する場合は、ログイン、公開範囲、削除・通報、モデレーション、保存先を要件化する。
