# Task Plan — Rookie Connect

## Visual thesis

落ち着いた NTT DATA ブルーを基調に、配属直後でも安心して声をかけられる、読みやすく親しみのあるタイムライン。

## Content plan

- 主画面: タイムラインと投稿作成
- 補助情報: 話題タグ、配属同期の一覧、プロフィール
- 詳細操作: いいねと返信

## Interaction thesis

- 初期表示でタイムラインと操作要素を段階的に表示する。
- いいねは即時に数と色が切り替わる。
- 返信フォームは投稿の文脈内で滑らかに開閉する。
