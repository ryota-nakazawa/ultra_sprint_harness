# インタビューサマリー — Project Pulse

## 依頼内容

- チームのタスクを管理するアプリを作りたい。
- タスク管理だけでなく、リスク管理もできるようにしたい。
- 最初に開く画面はダッシュボード。
- PoC はログインなし、ブラウザ内にデータを保存する。

## 合意済みの範囲

- タスクの追加、編集、完了管理
- リスクの追加、重要度、対応状況の管理
- 遅延タスクと高リスク項目をダッシュボードで優先表示
- プロジェクトによる絞り込み

## 対象外（PoC）

- ログイン、権限、メンバー招待
- 通知、外部ツール連携、クラウド共有
- 複数ユーザーのリアルタイム同期
