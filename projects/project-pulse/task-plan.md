# Project Pulse — タスク計画

## ビジュアル方針

- Visual thesis: NTT DATA系の深いブルーと淡いニュートラル面で、静かに優先順位を判断できる業務ダッシュボード。
- Content plan: ダッシュボード（優先事項）→ タスク運用 → リスク運用 → 保存状態のフィードバック。
- Interaction thesis: 画面切替の短いフェード、登録後のハイライト、進捗バーの更新アニメーション。

## 実施順

1. 評価設計とGate Aを通す。
2. static Web Appを実装する。
3. ローカルで自己確認する。
4. 独立評価サブエージェントでPlaywright評価を行う。
5. 結果を記録し、Fixなら最大2回まで修正する。
